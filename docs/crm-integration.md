# CRM 연동 정리 (REQ-07)

- **관련 요구사항**: REQ-07 CRM 등록 파일 생성
- **관련 유스케이스**: UC-08 CRM 등록 파일 다운로드
- **단계**: MVP

---

## 1. 개요

BranchSense는 CRM과 **단방향 파일 기반**으로 연동한다.

시스템이 접촉 명부(TOP 20)를 CSV/XLSX 파일로 생성하면, 담당자가 해당 파일을 기존 CRM에 직접 등록하는 방식이다. 양방향 실시간 API 연동은 Phase 3 이후 재검토한다.

```
BranchSense                          CRM
─────────────                        ─────────
접촉 명부 생성
  → 파일 다운로드 (CSV/XLSX)  →  담당자가 수동 업로드
```

---

## 2. 범위

### MVP 범위 (현재)
- 접촉 명부 → CRM 등록용 파일(CSV/XLSX) 생성 및 다운로드
- 수작업 편집 없이 CRM에 바로 올릴 수 있는 컬럼 구성

### Out of Scope
- CRM 양방향 실시간 API 연동 — Phase 3 이후 재검토
- CRM에서 태깅 결과를 역으로 받아오는 피드백 루프
- 실제 문자·알림톡 발송 — 초안 생성까지만, 발송은 기존 채널 담당

---

## 3. 파일 스펙

### 포맷
- CSV, XLSX 중 선택 가능

### 컬럼 구성 (CRM 컬럼 매핑은 별도 확인 필요)

| 컬럼 | 설명 | 비고 |
|------|------|------|
| 순위 | 접촉 우선순위 (1~20) | |
| 상호명 | 사업체 상호 | |
| 업종 | 업종 분류 | |
| 주소 | 사업체 소재지 | |
| 사업자번호 | 10자리 | |
| 영업상태 | 정상/휴업/폐업/영업정지 | 정상만 포함 |
| 선정사유 | 신호 기반 1줄 요약 | |
| 신호출처 | 소스명 · 기준일 | |
| 생성일 | 명부 생성 날짜 | |
| 지점코드 | 소속 지점 | |

> **미결 사항**: 실제 CRM 컬럼 매핑 스펙은 CRM 담당팀과 협의 필요 (`2-prd.md` 10장 미해결 이슈 4번)

### 인수 기준 (UC-08)
- 다운로드한 파일을 CRM에 등록할 때 **수작업 편집이 필요 없어야** 한다

---

## 4. 연동 흐름

```
1. 매일 07:30 배치 완료
       ↓
2. RM이 대시보드에서 접촉 TOP 20 확인
       ↓
3. "CRM 파일 다운로드" 버튼 클릭
       ↓
4. CSV / XLSX 파일 생성 및 다운로드
       ↓
5. RM이 기존 CRM에 파일 업로드
```

---

## 5. API 엔드포인트

FastAPI 기반으로 아래 엔드포인트를 제공한다.

```
GET /branches/{branch_id}/recommendations/export
  ?format=csv|xlsx
  &date=YYYY-MM-DD      # 생략 시 오늘
```

**응답**: 파일 다운로드 (Content-Disposition: attachment)

---

## 7. Phase 3 고도화 방향

현재는 파일 기반 단방향 연동이지만, Phase 3에서 아래를 검토한다.

- CRM API 직접 연동 (Push 방식)
- 태깅 결과를 CRM에서 역으로 수신 (양방향)
- CRM 내 접촉 이력과 BranchSense 채택률 연계
